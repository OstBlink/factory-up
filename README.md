# Конвейерия

Браузерная инкрементальная фабрика в духе Factorio. Ставишь буры на месторождения, тянешь конвейеры, перерабатываешь ресурсы в плавильнях, прессах и сборщиках и доставляешь на базу то, что она просит. За каждый доставленный предмет начисляется опыт. На новом уровне открываются здания и можно выбрать одно из 4 улучшений.

Стек: **TypeScript + Phaser 4 + Vite + GitHub Pages**. Вся графика и звуки создаются кодом, внешних файлов нет.

## Цель игры

- Выполнять задания базы: «Доставь N × предмет». За выполнение начисляется крупный бонус опыта, и сразу выдаётся новое задание.
- Расти в уровнях: открывать новые здания (пресс, литейная, сборщик, конструктор) и логистику (объединитель, сплиттер, мост).
- Строить всё более длинные цепочки: от руды до робота (руда → слиток → пластина/провод/сталь → схема/механизм → процессор/мотор → робот).

Проиграть нельзя, таймера нет. Первые шаги игре подсказывает обучение.

**Препятствие:** логистика — скалы и вода мешают прокладывать ленты, пропускная способность лент ограничена, заказы базы растут с уровнем.

## Управление

| Действие | Как |
|---|---|
| Камера | WASD или стрелки — движение, колесо мыши — зум, зажатая средняя кнопка — перетаскивание |
| Меню построек | **B** или **Tab**, кнопка «Постройки» слева |
| Поставить здание | выбрать в меню → ЛКМ по карте (зелёный «призрак» — можно, красный — нельзя) |
| Повернуть выход | **R** (бур сам смотрит выходом на базу, пока не нажат R) |
| Конвейер | **Q**, затем зажать ЛКМ и тянуть: лента ляжет буквой «Г». Клик ставит одну клетку |
| Удаление | **E**, затем ЛКМ или протяжка |
| Выйти из режима | **Esc** или ПКМ |
| Информация о здании | клик по зданию в обычном режиме (рецепт, буферы, смена рецепта) |
| Выбор улучшения | клик по карточке или клавиши **1–4** |

Стрелки на зданиях: **зелёные** — входы, **оранжевая** — выход.

## Запуск

```bash
npm install
npm run dev        # локальный сервер разработки
npm run typecheck  # проверка типов
npm run build      # production-сборка в dist/
npm run preview    # проверить сборку локально
```

Публикация: после push в ветку `main` GitHub Actions собирает игру и выкладывает её на GitHub Pages (`.github/workflows/deploy.yml`).

Прогресс сохраняется в `localStorage` (ключ `factory-game-save`) автоматически каждые 10 секунд и при закрытии вкладки.

## Где что лежит

Все числа баланса и контента (карта, предметы, рецепты, здания, опыт, улучшения, цвета) находятся в одном файле: **`src/game/balance.ts`**. Логика мира (`src/game/sim/`) написана на чистом TypeScript без Phaser. Сцены только рисуют мир и превращают ввод игрока в команды.

| Механика | Файл |
|---|---|
| Все числа и данные игры | `src/game/balance.ts` |
| Состояние мира, команды (поставить, удалить, рецепт), тик симуляции | `src/game/sim/World.ts` |
| Движение предметов по лентам | `src/game/sim/Belts.ts` |
| Буры и производство, порты зданий | `src/game/sim/Buildings.ts` |
| Объединитель, сплиттер, мост | `src/game/sim/Logistics.ts` |
| Опыт, уровни, открытия, улучшения | `src/game/sim/Progression.ts` |
| Задания базы | `src/game/sim/Goals.ts` |
| Сохранение и загрузка | `src/game/sim/Save.ts` |
| Проверка проходимости карты (dev) | `src/game/sim/MapCheck.ts` |
| Текстуры, нарисованные кодом | `src/game/BootScene.ts` |
| Стартовый экран | `src/game/MenuScene.ts` |
| Камера, режимы, ввод на карте | `src/game/GameScene.ts` |
| Отрисовка мира и эффекты | `src/game/WorldView.ts` |
| HUD, обучение | `src/game/UIScene.ts`, `src/game/ui/` |
| Звуки (Web Audio) | `src/game/Sound.ts` |
